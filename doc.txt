GetSeen Mobile API Documentation
Overview
This document describes the mobile API endpoints for connecting the GetSeen mobile app to the GetSeen backend.


The mobile integration currently supports:

Advertisers
Screen owners

Admin functionality is not included in the current mobile API phases.

Environment
Base URL:

https://www.trygetseen.com/api/v1

All requests should use JSON:

Content-Type: application/json

Accept: application/json

Protected endpoints require:

Authorization: Bearer <access_token>

Standard Responses
Success response:

{

  "success": true,

  "data": {}

}

Error response:

{

  "success": false,

  "error": {

    "code": "ERROR_CODE",

    "message": "Human readable error message."

  }

}

Validation error response:

{

  "success": false,

  "error": {

    "code": "VALIDATION_ERROR",

    "message": "The submitted information is invalid.",

    "fields": {

      "email": "A valid email address is required."

    }

  }

}
Authentication Overview
The mobile app uses token-based authentication.

After registration or login, the backend returns:

access_token: used on protected API requests.
refresh_token: used to get a new access token when the old one expires.

The mobile app should store tokens securely using platform secure storage.

Upload Cart Media
POST /advertiser/cart/{item_id}/media

Authentication: Required

Role: Advertiser only

Content type:

multipart/form-data

Multipart fields for a new upload:

media_type=image

media=<file>

Allowed media types:

image - JPG, JPEG, PNG

video - MP4

Success response:

{

  "success": true,

  "data": {

    "message": "Media uploaded successfully.",

    "item": {},

    "media": {

      "filename": "abc123.png",

      "media_type": "image",

      "source": "uploaded",

      "url": "https://www.trygetseen.com/static/images/cart_items/abc123.png"

    },

    "cart": {}

  }

}

Select Existing Media
Use the same endpoint:

POST /advertiser/cart/{item_id}/media

Content type:

multipart/form-data

Multipart fields:

media_type=image

existing_media=abc123.png

This attaches an existing uploaded/order media file to the cart item.

Phase 7: Checkout And Payment
Phase 7 lets advertisers turn a ready cart into a Paystack payment.

Checkout is only for digital screen bookings in this phase. Amplify/retargeting checkout is not included yet.

Before checkout:

The advertiser must have at least one cart item.

Every cart item must have uploaded or selected media.
